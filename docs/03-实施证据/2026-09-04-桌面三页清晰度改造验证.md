# 桌面三页清晰度改造验证

## 范围

客户列表、客户详情、经营看板及其专用展示组件。保留青绿主色，以分区、边界、字重、对齐和可阅读宽度提高清晰度；不回退业务布局，不修改后端、权限、统计口径、数据库或移动端。

公共规则位于 `apps/web/src/styles/operations-surface.css`，仅三个页面根节点显式启用。双端共享令牌及桌面侧栏未改。正式设计规则见《交互设计打磨》§1.5、《PRD》§4.3。

## 验证

- 桌面端 11 个测试文件、23 项测试通过。覆盖客户池查询及客户名称导航、商机卡开放项排序/键盘导航/结案呈现、客户活动导航、资料单列及编辑权限显隐，以及原有看板周期/请求竞态用例。
- `pnpm --filter @crm/web build` 通过，包含 `vue-tsc -b` 类型检查和生产构建。已有主包超过 500 kB 提示仍保留，未扩展到打包优化。
- 使用真实 Vue 页面及 Element Plus 组件做浏览器视觉检查，预览数据在页面内模拟，所有非 GET 请求拒绝，不连接业务数据库、不写入真实登录会话。
- 客户列表：检查长名称换行、客户池与搜索分区、表头层次及名称链接；窄桌面仍保留表格自身横向滚动。
- 客户详情：1280/1080 宽度下主栏独立、资料移到下方；1440 宽度下 340px 侧栏正常，`¥12,860,400` 完整显示，编码及网址可换行。1080 宽度再次核验客户名称与按钮分行，无重叠。
- 经营概览：1440/1080 宽度检查当前池、三段横向构成、期间选择、三项指标及关注客户；金额没有被截断，月份控件未与指标重叠。
- 浏览器验证不等于带真实后端的完整业务回归；本次未执行新增、移交、释放等数据库写操作，也未逐个视觉验收经营看板的所有页签。

## 部署边界

仅需发布桌面端构建产物，无后端更新、迁移或数据重导要求。用于视觉验收的临时页面和模拟数据位于已忽略的 `docs/areas/`，不进入应用入口、生产构建或 Git 提交。
