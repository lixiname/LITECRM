# 当前有效文档：阅读顺序

本目录是 Lite CRM 当前唯一设计基线。推荐顺序：

1. `CRM业务设计方法与成熟产品借鉴.md`：为什么这样建设，以及如何借鉴成熟经验。
2. `PRD.md`：做什么、谁来做、业务规则和验收结果。
3. `重构架构决策与实施蓝图.md`：模型、权限、事务、接口和技术边界。
4. `交互设计打磨.md`：页面如何呈现、入口如何衔接。
5. `技术打磨清单.md`：开发必须遵守的质量门禁。
6. `测试体系与编写指南.md`：如何验证实现。
7. `云端部署与数据库运维.md`：如何首次建库、初始化基础数据并安全发布后续版本。

日常修改无需每次全部阅读：先从任务直接对应的文档进入，再按根目录 [`docs/README.md`](../README.md) 的任务索引补充上下文。

本目录不保存实施日志、临时排期或旧版本方案；那些材料分别位于 `03-实施证据` 和 `99-历史归档`。
